# SvelteKit Mobile Starter Template
A lightweight starter template for building mobile-friendly apps with SvelteKit.
Built for fast development, clean structure, and reusable UI components.

## Features

- SvelteKit + TypeScript
- Mobile-first layout
- Lightweight and fast
- Reusable UI components
- Toast system
- DaisyUI-based styling
- Easy to extend

## Styling

This project uses DaisyUI and Tailwind CSS for fast component styling.

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
